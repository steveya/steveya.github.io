# Malaria Detection Workflow

## Purpose

Use this area for shared instructions governing the full malaria-detection series.

## Scope

This file is the local runbook for series-level work on `malaria-detection-*`.

## What Counts as Progress

- stronger data and model pipeline
- more rigorous evaluation of detection performance
- clearer error analysis and practical interpretation

## Evidence Expectations

- Keep data-handling assumptions explicit.
- Use rigorous evaluation rather than headline metrics alone.
- Include practical interpretation of errors and limitations.

## Workflow Expectations

- Treat the series as one workflow, not as isolated posts.
- Locate the current frontier before editing.
- Update `codex-workflows/malaria-detection-log.md` after a substantive branch.
- Keep pipeline changes, model changes, and evaluation changes clearly separated when possible.

## Deliverables

- Updated narrative or draft notebook for the series
- Clear statement of the pipeline or evaluation improvement
- Updated `codex-workflows/malaria-detection-log.md`
