\section{Discrete OU Model}

This section will introduce the exact discrete-time Ornstein-Uhlenbeck mispricing model
\[
X_i = a X_{i-1} + \varepsilon_i
\]
where \(a = e^{-\theta \Delta}\), and derive the stationary return autocovariance. The main proposition should establish that one-period returns have negative autocovariance under the stationary model.
